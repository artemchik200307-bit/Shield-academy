# S.H.I.E.L.D. Academy V22 — Self-Research Curriculum

Principle:
The Academy tells the learner WHAT to study and WHAT to do.
The learner finds, evaluates, compares, processes and explains the information.

Daily:
- Physical — unchanged.
- English — topic + official source + tasks.
- Deutsch — topic + official source + tasks.
- One rotating cognitive discipline — topic + official source + research tasks + retrieval.
- Работа с информацией — 10-минутный самостоятельный анализ информации.
- Agent Log — short ИТОГ ДНЯ.

The old long instructional/answer-like blocks were removed. Existing official sources were retained.
